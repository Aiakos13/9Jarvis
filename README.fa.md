# 9Jarvis 🤖

> دستیار شخصی ماژولار با هوش مکالمه‌ای، حافظهٔ محلی، ابزارها و تعامل آزمایشی با دسکتاپ ویندوز.

**زبان‌ها:** [English](README.md) · فارسی · [Türkçe](README.tr.md)

9Jarvis پروژه‌ای عمومی برای بررسی ساخت دستیار هوش مصنوعی شخصی است؛ دستیاری که می‌تواند درخواست‌ها را بفهمد، زمینهٔ مرتبط را بازیابی کند، از ابزارها استفاده کند و با دسکتاپ ویندوز تعامل داشته باشد. برخی قابلیت‌ها پیاده‌سازی شده‌اند؛ تعامل با دسکتاپ همچنان آزمایشی است و ممکن است در برنامه‌های مختلف رفتار متفاوتی داشته باشد.

## قابلیت‌ها و وضعیت

- **گفت‌وگو:** پاسخ‌ها از طریق OpenRouter و با مدل `openai/gpt-oss-20b` که در کد فعلی تنظیم شده است تولید می‌شوند.
- **Agent:** تصمیم‌گیری دربارهٔ ابزارها از طریق یک نشانی محلی سازگار با Ollama انجام می‌شود. نشانی پیش‌فرض `http://localhost:11434/v1` و مدل پیش‌فرض `qwen3:4b-instruct` است.
- **حافظه:** اطلاعات انتخاب‌شدهٔ کاربر و پروژه به‌صورت محلی در `memory.json` ذخیره می‌شوند و ممکن است در زمینهٔ مرتبط استفاده شوند.
- **ابزارها:** ماشین‌حساب، زمان، تاریخ، عدد تصادفی، جست‌وجوی وب، مکان‌یابی، آب‌وهوا، نرخ ارز، اجرای برنامه و مرورگر، بستن و فعال‌کردن برنامه، ورودی صفحه‌کلید و ماوس، پیمایش و اسکرین‌شات.
- **بینایی:** اسکرین‌شات‌ها می‌توانند از طریق OpenRouter و با مدل بینایی تنظیم‌شده در کد فعلی، یعنی `deepseek/deepseek-v4.1-flash`، تحلیل شوند.
- **تعامل با دسکتاپ (آزمایشی):** ابزارهای مخصوص ویندوز می‌توانند برنامه‌ها را اجرا و ببندند، URLها را باز کنند، اسکرین‌شات بگیرند و تحلیل کنند و اقدام‌های پشتیبانی‌شدهٔ ماوس و صفحه‌کلید را انجام دهند. برنامه‌ها قابل اجرا و بسته‌شدن هستند؛ URLها فقط باز می‌شوند. ورود متن از Windows UI Automation برای هدف‌گیری ویرایشگر متن Notepad استفاده می‌کند.

جست‌وجوی وب از Tavily استفاده می‌کند و به کلید API آن نیاز دارد. مکان‌یابی و آب‌وهوا از APIهای Open-Meteo استفاده می‌کنند. نرخ ارز از Frankfurter دریافت می‌شود.

## پیش‌نیازها

- ویندوز به‌همراه PowerShell.
- Node.js و npm.
- Git.
- کلید API از OpenRouter.
- اجرای Ollama روی سیستم محلی، همراه با مدل تنظیم‌شده، برای تصمیم‌گیری Agent دربارهٔ ابزارها.
- کلید API از Tavily فقط در صورت نیاز به جست‌وجوی وب.

پشتیبانی از سیستم‌عامل‌های دیگر مستند نشده است.

## نصب و پیکربندی

```powershell
git clone https://github.com/Aiakos13/9Jarvis.git
cd 9Jarvis
npm install
Copy-Item .env.example .env
```

مقدار `OPENROUTER_API_KEY` را در فایل محلی `.env` تنظیم کنید. اگر به جست‌وجوی وب نیاز دارید، `TAVILY_API_KEY` را نیز اضافه کنید. تنظیمات Agent را می‌توان با `OLLAMA_BASE_URL` و `OLLAMA_MODEL` تغییر داد؛ مقدارهای پیش‌فرض آن‌ها `http://localhost:11434/v1` و `qwen3:4b-instruct` هستند.

فایل `.env` را commit نکنید و کلیدهای API را به اشتراک نگذارید. اطلاعات محرمانه را در مستندات یا اسکرین‌شات‌ها قرار ندهید.

## اجرا

```bash
npm start
```

در `package.json` ریشه، این دستور معادل `node main.js` است. اجرای مستقیم `node main.js` هم امکان‌پذیر است.

## آزمون‌ها

برای اجرای اسکریپت آزمون Agent:

```bash
node test-agent.js
```

این اسکریپت نتیجهٔ آزمون‌های تجزیه و فراخوانی بومی ابزارها را چاپ می‌کند. دستور `npm test` در ریشهٔ مخزن این آزمون‌ها را اجرا نمی‌کند؛ فعلاً جای‌نگهدار است، پیامی چاپ می‌کند و با خطا خارج می‌شود.

## ایمنی و حریم خصوصی

ابزارهای دسکتاپ می‌توانند ورودی ماوس و صفحه‌کلید بفرستند، برنامه‌ها را اجرا کنند و فرایند برنامه‌ها را به‌اجبار ببندند. هنگام استفاده بر آن‌ها نظارت کنید و برای کارهای حساس یا برگشت‌ناپذیر به آن‌ها اتکا نکنید. محتوای اسکرین‌شاتی که برای تحلیل بینایی فرستاده می‌شود از طریق ارائه‌دهندهٔ مدل تنظیم‌شده پردازش می‌شود؛ پیش از استفاده، سیاست دادهٔ آن سرویس را بررسی کنید. حافظه در فایل محلی `memory.json` ذخیره می‌شود و ممکن است اطلاعات شخصی داشته باشد.

## محدودیت‌ها و نقشهٔ راه

تعامل با کامپیوتر همچنان در حال توسعه است. تشخیص عناصر با بینایی و اقدام‌های مبتنی بر مختصات ممکن است نادرست باشند. پیاده‌سازی فعلی UI Automation برای ورود متن، مشخصاً ویرایشگر متن Notepad را هدف می‌گیرد؛ این پیاده‌سازی به‌معنای پشتیبانی عمومی از UI Automation در همهٔ برنامه‌های دسکتاپ نیست. گردش‌کارهای خودکار، تعامل صوتی و رابط گرافیکی برنامه‌ریزی شده‌اند و قابلیت فعلی محسوب نمی‌شوند.
