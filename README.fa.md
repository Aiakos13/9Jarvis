# 🤖 9Jarvis

> دستیار هوش مصنوعی شخصی و ماژولاری که به‌صورت مرحله‌ای توسعه می‌یابد و هوش مکالمه‌ای، حافظهٔ محلی، ابزارها و تعامل آزمایشی با دسکتاپ ویندوز را ترکیب می‌کند.

**زبان‌ها:** [English](README.md) · فارسی · [Türkçe](README.tr.md)

9Jarvis پروژه‌ای عمومی برای بررسی معماری دستیارهای هوش مصنوعی شخصی است. پروژه در حال توسعه است: گفت‌وگو، حافظهٔ محلی و جریان Agent و ابزار پیاده‌سازی شده‌اند؛ تعامل با کامپیوتر همچنان آزمایشی است. گردش‌کارهای خودکار، تعامل صوتی و رابط گرافیکی قابلیت فعلی نیستند و برای آینده برنامه‌ریزی شده‌اند.

## ✨ نمای کلی

9Jarvis بر پایهٔ معماری ماژولار و توسعهٔ مرحله‌ای پیش می‌رود:

> **یک تغییر ← آزمایش ← بررسی نتیجه ← مرحلهٔ بعد**

برنامهٔ خط فرمان، مدل گفت‌وگویی OpenRouter را با Agent محلیِ سازگار با Ollama ترکیب می‌کند. Agent ابزارها را انتخاب و اجرا می‌کند و پیش از اجرا، فراخوانی ابزار اعتبارسنجی می‌شود. حافظهٔ انتخاب‌شده در فایل JSON محلی ذخیره می‌شود.

## 🚀 قابلیت‌ها و وضعیت

| مؤلفه | توضیحات | وضعیت |
| --- | --- | --- |
| هستهٔ هوش مصنوعی | تولید پاسخ مکالمه‌ای از طریق OpenRouter | پیاده‌سازی‌شده |
| حافظه | ذخیرهٔ محلی اطلاعات انتخاب‌شدهٔ کاربر/پروژه و بازیابی آن در قالب زمینه | پیاده‌سازی‌شده |
| ابزارها | ابزارهای کاربردی، جست‌وجوی وب، آب‌وهوا، ارز و تعامل با ویندوز | پیاده‌سازی‌شده؛ با محدودیت |
| Agent | انتخاب ابزار با مدل محلی، اعتبارسنجی، اجرا و چرخهٔ چندمرحله‌ای محدود | پیاده‌سازی‌شده |
| تعامل با کامپیوتر | ابزارهای برنامه، صفحه‌کلید/ماوس، اسکرین‌شات و بینایی در ویندوز | آزمایشی؛ میزان اطمینان متغیر است |
| خودکارسازی، صدا و رابط گرافیکی | توسعه‌های آینده | برنامه‌ریزی‌شده |

### مدل‌ها و سرویس‌ها

- گفت‌وگو و پاسخ نهایی: `openai/gpt-oss-20b` از طریق OpenRouter.
- تحلیل بینایی اسکرین‌شات: `deepseek/deepseek-v4.1-flash` از طریق OpenRouter.
- تصمیم‌گیری Agent دربارهٔ ابزارها: API محلی سازگار با Ollama. مقدارهای پیش‌فرض `http://localhost:11434/v1` و `qwen3:4b-instruct` هستند و با متغیرهای محیطی قابل تغییرند.
- جست‌وجوی وب: Tavily؛ به `TAVILY_API_KEY` نیاز دارد.
- مکان‌یابی و آب‌وهوا: APIهای Open-Meteo.
- نرخ ارز: Frankfurter.

### ابزارهای موجود

`calculator`، `time`، `date`، `random`، `web_search`، `geocode`، `weather`، `currency`، `open_app`، `open_url`، `close_app`، `press_key`، `hotkey`، `focus_app`، `type_text`، `open_default_browser`، `mouse_click`، `mouse_move`، `mouse_double_click`، `scroll` و `screenshot`.

ابزارهای برنامه می‌توانند برنامه‌ها را اجرا و ببندند؛ ابزارهای URL فقط نشانی‌ها را باز می‌کنند و آن‌ها را نمی‌بندند. ورود متن در حال حاضر با Windows UI Automation و با هدف‌گیری ویرایشگر متن Notepad انجام می‌شود. این به‌معنای پشتیبانی عمومی UI Automation در همهٔ برنامه‌های دسکتاپ نیست. تشخیص تصویری و اقدام‌های مبتنی بر مختصات ممکن است نادرست باشند.

## 🏗️ معماری

```text
درخواست کاربر
    ↓
main.js — خط فرمان، زمینهٔ حافظه و پاسخ نهایی
    ↓
agent.js — تصمیم Agent محلی برای فراخوانی ابزار
    ↓
toolValidator.js — اعتبارسنجی ابزار و آرگومان‌ها
    ↓
tools.js — اجرای عملیات و برگرداندن نتیجه
    ↓
چرخهٔ Agent — ادامه یا پایان (با محدودیت تعداد مرحله و تلاش)
```

ماژول‌های اصلی شامل `main.js`، `config.js`، `agent.js`، `toolValidator.js`، `tools.js`، `memory.js`، `memoryDetector.js` و `memoryQueryDetector.js` هستند. Agent حداکثر ۵ مرحله و ۲ تلاش مجدد برای هر درخواست اقدام دارد.

حافظه در فایل `memory.json` در پوشهٔ کاری پروژه ذخیره می‌شود و ممکن است شامل اطلاعات شخصی باشد؛ پیش از اشتراک‌گذاری پوشه یا نسخهٔ پشتیبان، آن را بررسی کنید.

## ⚙️ پیش‌نیازها و نصب

### پیش‌نیازها

- ویندوز و PowerShell (ابزارهای مستندشدهٔ دسکتاپ مخصوص ویندوز هستند).
- Node.js و npm.
- Git.
- کلید API از OpenRouter.
- اجرای Ollama روی سیستم محلی با مدل تنظیم‌شده برای تصمیم‌گیری Agent دربارهٔ ابزارها.
- کلید API از Tavily فقط در صورت استفاده از جست‌وجوی وب.

### نصب

```powershell
git clone https://github.com/Aiakos13/9Jarvis.git
cd 9Jarvis
npm install
Copy-Item .env.example .env
```

مقدار `OPENROUTER_API_KEY` را در فایل محلی `.env` تنظیم کنید. `TAVILY_API_KEY` را فقط در صورت نیاز به جست‌وجوی وب اضافه کنید. نشانی و مدل Agent را می‌توان با `OLLAMA_BASE_URL` و `OLLAMA_MODEL` تغییر داد؛ مقدارهای پیش‌فرض آن‌ها `http://localhost:11434/v1` و `qwen3:4b-instruct` هستند.

فایل `.env` یا کلیدهای API را commit یا منتشر نکنید. فایل `.env.example` موجود در مخزن فقط شامل جای‌نگهدار است و اعتبارنامهٔ قابل‌استفاده ندارد.

## 💬 استفاده

رابط خط فرمان را اجرا کنید:

```bash
npm start
```

در `package.json` ریشه، `npm start` معادل `node main.js` است. برای خروج، `exit` را وارد کنید.

نمونهٔ درخواست‌ها:

```text
ساعت چنده؟
25 * 18
خبرهای جدید را در وب جست‌وجو کن
هوای Berlin چطور است؟
Notepad را باز کن
```

جست‌وجوی وب به تنظیم Tavily نیاز دارد. درخواست آب‌وهوا ابتدا از مکان‌یابی و سپس از API آب‌وهوا استفاده می‌کند. نمونه‌های کنترل دسکتاپ به ویندوز نیاز دارند و باید با نظارت اجرا شوند.

## 🧪 آزمون‌ها

آزمون‌های تجزیه و فراخوانی بومی ابزارهای Agent را اجرا کنید:

```bash
node test-agent.js
```

دستور ریشهٔ `npm test` این اسکریپت را اجرا **نمی‌کند**. این دستور فعلاً جای‌نگهدار است؛ پیام «Tests have not been configured yet» را چاپ می‌کند و با خطا خارج می‌شود. برای بررسی نحو فایل‌های منتخب می‌توان از `node --check <file>` استفاده کرد.

## 🛡️ ایمنی و حریم خصوصی

ابزارهای دسکتاپ می‌توانند ورودی صفحه‌کلید و ماوس بفرستند، برنامه‌ها را اجرا کنند و فرایند برنامه‌ها را به‌اجبار ببندند. بر استفاده نظارت داشته باشید و برای کارهای حساس یا برگشت‌ناپذیر به آن‌ها اتکا نکنید. اسکرین‌شات‌های ارسالی برای تحلیل بینایی به ارائه‌دهندهٔ مدل تنظیم‌شده فرستاده می‌شوند؛ سیاست دادهٔ ارائه‌دهنده را بررسی کنید و از نمایش اطلاعات خصوصی روی صفحه بپرهیزید. حافظه در `memory.json` محلی نگهداری می‌شود و ممکن است اطلاعات شخصی داشته باشد.
